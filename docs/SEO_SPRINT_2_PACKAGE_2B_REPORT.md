## 3. Детализация реализованных страниц

### 3.1. Услуга `/services/interactive-design`
- **H1:** «Интерактивный дизайн и визуальные wow-эффекты на GLSL и Three.js»
- **Ключевые разделы:**
  - *Эмоциональный первый экран:* захват внимания в первые 3 секунды, удержание посетителея.
  - *4 сценария применения:* 1) динамический первый экран, 2) шейдерные переходы и жидкое стекло (glass refraction / chromatic aberration), 3) кинетическая типографика, 4) физика частиц и курсора (GPGPU-шейдеры, bloom).
  - *Инженерные стандарты:* 60 FPS на десктопе, поддержка директивы `prefers-reduced-motion: reduce`, ленивая инициализация WebGL через `IntersectionObserver` и экономия батареи мобильных GPU.
  - *5 этапов продакшна:* концепт-борд, шейдерный прототип, профилирование FPS, бесшовная интеграция в DOM-лейаут, кросс-браузерное тестирование.
  - *FAQ:* 4 инженерных ответа (читаемость через жидкое стекло, производительность на смартфонах, доступность, внедрение в работающий сайт).

### 3.2. Услуга `/services/speed-optimization`
- **H1:** «Ускорение сайта и оптимизация Core Web Vitals до 95+ баллов»
- **Ключевые разделы:**
  - *Инженерная диагностика:* аудит в Chrome DevTools и CrUX перед началом работ.
  - *4 направления оптимизации:* 1) LCP и критический путь рендера (critical CSS, preload), 2) устранение задержек INP в главном потоке JS (requestIdleCallback), 3) стабилизация CLS (aspect-ratio, font-display: optional), 4) современные ассеты (WebP/AVIF, сабсеттинг WOFF2, Brotli).
  - *Сравнительная матрица «До / После»:* прозрачное сопоставление технических параметров (TTFB, FCP, LCP, INP, CLS, вес страницы).
  - *Регламент внедрения:* 5 этапов от замера до сдачи с контрольными отчетами.
  - *FAQ:* 4 коммерческих ответа (гарантия 95+ баллов, отличия лабораторных тестов от CrUX, отсутствие необходимости переписывать сайт, неизменность дизайна).

### 3.3. Услуга `/services/vanilla-js`
- **H1:** «Кастомная веб-разработка на чистом JavaScript без оверхеда фреймворков»
- **Ключевые разделы:**
  - *Антикризис перегруженного веба:* почему 500+ КБ JS ради формы и слайдера — фатальная ошибка для конверсии.
  - *Преимущества архитектуры:* мгновенный старт (FCP < 0.5 с), идеальный контроль над Canvas/WebGL контекстом, срок жизни кода 5+ лет без обновления библиотек, нулевая поверхность атак уязвимостей.
  - *Сравнительная матрица по 6 критериям:* Tilda / CMS Bitrix vs React / Next.js SPA vs Zero-Build Vanilla JS (VOID).
  - *Целевые сегменты:* промо-сайты, интерактивные конфигураторы, B2B-витрины, высоконагруженные лендинги.
  - *FAQ:* 4 вопроса (понятие Zero-Build, замена скриптов на работающем сайте, обновление контента без CMS, передача кода сторонним разработчикам).
