## 1. Резюме спринта

В рамках реализации **Спринта 1 (Quick Wins)** из дорожной карты SEO-оптимизации студии VOID | digital выполнен полный комплекс работ по технической гигиене, устранению критических замечаний аудита и семантической микроразметке. 

Все работы выполнены локально детерминированными скриптами и инструментами валидации без привлечения генеративного транспорта Hermes/Luna.

## 2. Перечень выполненных задач

### 2.1. Исправление и актуализация `sitemap.xml`
- **Проблема:** Аудит выявил в карте сайта невалидный URL `https://void-digital.ru/consent` (отдававший 404).
- **Решение:**
  - Удален несуществующий URL `https://void-digital.ru/consent`.
  - Карта сайта синхронизирована с 9 каноническими страницами: `/`, `/services`, `/portfolio`, `/about`, `/contacts`, `/blog`, `/blog-brief`, `/blog-landing-vs-site`, `/privacy`.
  - Для всех 9 страниц актуализирован тег `<lastmod>2026-11-17</lastmod>`.
  - Валидность XML подтверждена парсером `xml.etree.ElementTree`.

### 2.2. Защита служебных данных в `_redirects`
- **Проблема:** Служебные файлы проекта (`void-digital-semantics.md`, `content_plan.csv`, `.json`) могли быть доступны для прямой индексации поисковыми роботами.
- **Решение:**
  - В файл `_redirects` добавлены правила 301-редиректа на главную страницу:
    ```apache
    /content_plan.csv / 301
    /void-digital-semantics.md / 301
    /*.md / 301
    /*.json / 301
    /*.csv / 301
    ```

### 2.3. Исправление форматирования семантической карты (`void-digital-semantics.md`)
- **Проблема:** В кластере C13 (строка 1014) и ряде других строк таблицы не были экранированы вертикальные черты `void | digital`, что ломало структуру Markdown-таблицы.
- **Решение:** Выполнено корректное экранирование пайпов `void \| digital` во всех ячейках таблицы семантики. Файл синхронизирован в репозитории `site/` и рабочей директории `claude/`.

### 2.4. Заполнение отсутствующих `alt`-атрибутов изображений
- **Проблема:** В `index.html` у изображения жилого комплекса «Соцветие» присутствовал пустой атрибут `alt=""`.
- **Решение:**
  - Установлен семантически точный атрибут: `alt="Главный экран сайта жилого комплекса «Соцветие»"`.
  - Проведен полный автоматический аудит всех 10 HTML-файлов: подтверждено, что пустых атрибутов `alt=""` на сайте больше нет (все изображения портфолио, иконки и иллюстрации снабжены контекстными описаниями).

### 2.5. Унификация внутренних ссылок (Clean URLs без `.html`)
- **Проблема:** В меню, футерах и текстовых ссылках присутствовали жесткие ссылки с расширением `.html` (`services.html`, `index.html` и др.), что создавало потенциал для дублирования страниц в индексе.
- **Решение:**
  - Разработан и выполнен скрипт нормализации ссылок во всех 10 HTML-файлах (`404.html`, `about.html`, `blog-brief.html`, `blog-landing-vs-site.html`, `blog.html`, `contacts.html`, `index.html`, `portfolio.html`, `privacy.html`, `services.html`) и в `js/main.js`.
  - Все внутренние ссылки переведены на канонический формат без `.html`:
    - `index.html` → `/`
    - `services.html` → `/services`
    - `portfolio.html` → `/portfolio`
    - `about.html` → `/about`
    - `contacts.html` → `/contacts`
    - `blog.html` → `/blog`
    - `blog-brief.html` → `/blog-brief`
    - `blog-landing-vs-site.html` → `/blog-landing-vs-site`
    - `privacy.html` → `/privacy`
    - `404.html` → `/404`
  - Все якорные ссылки (`/services#calc`, `/#b2b`) и query-параметры сохранены корректно.

### 2.6. Внедрение микроразметки Schema.org (JSON-LD)
- **Проблема:** До спринта разметка Schema.org присутствовала только на главной странице (`index.html`). Остальные 9 страниц не содержали структурированных данных для поисковых сниппетов.
- **Решение:**
  - Внедрена семантическая разметка Schema.org формата JSON-LD на все страницы:
    1. **`services.html`** → `@type: "Service"` с расширенным каталогом предложений `OfferCatalog` (Лендинги от 18 000 ₽, Корпоративные сайты от 35 000 ₽, Интернет-магазины от 45 000 ₽, 3D WebGL и редизайн) + привязка к `provider` (VOID | digital).
    2. **`portfolio.html`** → `@type: "CollectionPage"` с описанием портфолио проектов агентства.
    3. **`about.html`** → `@type: "AboutPage"` с сущностью `mainEntity` типа `ProfessionalService` (описание студии, стек технологий, основатели, контакты).
    4. **`contacts.html`** → `@type: "ContactPage"` с полными реквизитами, email, Telegram и часами работы.
    5. **`blog.html`** → `@type: "Blog"` со списком публикаций и описанием экспертизы.
    6. **`blog-brief.html`** → `@type: "Article"` (автор VOID | digital, дата публикации, тематика разработки брифов).
    7. **`blog-landing-vs-site.html`** → `@type: "Article"` (автор VOID | digital, руководство по выбору между лендингом и многостраничным сайтом).
    8. **`privacy.html`** → `@type: "WebPage"` с указанием политики обработки персональных данных.
    9. **`404.html`** → `@type: "WebPage"` для страницы ошибки.
  - Все 10 JSON-LD блоков проверены синтаксическим анализатором: 0 ошибок, 100% валидность.

### 2.7. Хеширование статических ассетов
- Запущен скрипт `scripts/version-assets.py`.
- Актуализированы query-хеши для стилей (`style.css?v=55899e35`) и скриптов (`main.js?v=1c546b46`) во всех HTML-файлах для сброса кэша браузеров и CDN.

## 3. Результаты автоматизированного тестирования (Playwright)

Для валидации целостности сайта и отсутствия регрессий выполнен прогон тестового комплекса Playwright (`tests/site.spec.js`):
- **Среда:** Локальный статический веб-сервер Python (`http://127.0.0.1:8080`), движки **Chromium (Desktop)** и **WebKit (iPhone 13)**.
- **Итог прогона:**
  - **Всего тестов:** 40
  - **Пройдено успешно (Passed):** 38
  - **Пропущено (Skipped):** 2 (опциональные сценарии окружения)
  - **Ошибок (Failed):** 0
- **Ключевые проверенные сценарии:**
  - Все 10 страниц возвращают HTTP 200, имеют корректный заголовок `VOID | digital`, видимый `<h1>` и нулевое количество ошибок в консоли браузера.
  - Интерактивный калькулятор: корректный расчет стоимости (Лендинг + CRM = 18 000 – 24 000 ₽; Лендинг + 3D = 23 000 – 30 000 ₽).
  - Скрытие нерелевантных опций («Онлайн-оплата» для магазина).
  - Формирование предзаполненного сообщения в Telegram (прямой лидген без локальных форм сбора ПДн).
  - Загрузка интерактивной 3D-сцены WebGL в темной секции главной страницы.
  - Мобильная верстка: проверка минимального размера полей (>= 16px), отсутствие горизонтального скролла, поведение плавающей нижней панели.
